Тестирование
Тестирование проекта выполнено с помощью фреймворка pytest. Покрытие включает нормальные сценарии, граничные случаи и обработку ошибок.

Какие сценарии протестированы
Проверка выброса ошибки при неверной валюте. Тест подтверждает, что функция filter_by_currency выбрасывает ValueError, если передана неподдерживаемая валюта. Проверка реализована через контекстный менеджер pytest.raises(ValueError).
Корректная фильтрация по валидной валюте. Проверяется, что при передаче поддерживаемой валюты (например, "RUB") возвращается ожидаемый список транзакций. Используются утверждения assert для проверки длины результата и содержимого элементов.
Обработка пустого списка. Проверяется поведение функции при пустом входном списке: ожидается пустой результат.
Как устроены тесты
Фикстуры. Для подготовки тестовых данных используется фикстура sample_transactions в файле tests/conftest.py. Это позволяет избежать дублирования данных и делает тесты чище.
Стиль проверок. Все проверки выполнены через оператор assert. Это даёт понятные сообщения об ошибках при провале теста.
Структура файлов. Тесты расположены в папке tests/, отдельный файл test_filter_by_currency.py содержит тесты для функции filter_by_currency.
