Проект имеет правильную структуру (src/ и tests/), функции get_mask_card_number и get_mask_account реализованы, покрыты тестами, включая тесты на валидацию входных данных. Аннотации типов указаны, логика соответствует требованиям.

Из‑за ограничений сетевой среды (ошибки DNS, невозможность доступа к PyPI и install.python-poetry.org) не удалось установить Poetry и линтеры (black, isort, flake8, mypy) в виртуальное окружение.

Форматирование кода выполнено встроенными средствами PyCharm (Reformat Code, Optimize Imports), что обеспечивает соответствие стандартам PEP 8 и стилю black. Конфигурационные файлы (pyproject.toml, .flake8 и др.) подготовлены к заполнению; зависимости будут добавлены через poetry add при восстановлении сетевого доступа.

Приложены скриншоты: панель Run с результатами тестов (все PASSED) и отформатированный код функций в `src/masks.py
