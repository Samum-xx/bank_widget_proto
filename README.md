# bank-widget-clean

Банковский виджет для обработки финансовых операций: чтение транзакций из разных форматов, конвертация валют, фильтрация и маскирование номеров счетов.

## Особенности реализации

- **Чтение данных из разных источников**:
  - CSV (разделитель `;`) — реализовано через `csv`.
  - XLSX — реализовано через `openpyxl`.
  - JSON — реализовано через встроенный модуль `json`.
- **Конвертация валют**: получение курса через внешний API и конвертация сумм в рубли.
- **Маскирование счетов**: функция `get_mask_account` для безопасного отображения номеров.
- **Тестирование**: покрытие тестами через `pytest`, включая моки для API.
- **Качество кода**: линтеры `flake8`, `isort`, типизация `mypy`, управление зависимостями через `Poetry`.

## Новые модули и структура (feature/decorators)

Добавлены два новых модуля для работы с данными:

### "src/readers"
Пакет для низкоуровневого чтения файлов:
- "read_csv(path: str) -> List[Dict]" — чтение CSV через "csv.DictReader".
- "read_excel(path: str) -> List[Dict]" — чтение Excel через "openpyxl.load_workbook()".

### "src/utils"
Утилиты для загрузки и базовой обработки данных:
- "load_operations(path: str) -> List" — загрузка операций из JSON с обработкой ошибок.
- Вспомогательные функции для чтения транзакций.

### "Функционал":
- Считывание транзакций из CSV и Excel.
- Конвертация валют (с поддержкой переопределения курса для тестов).
- Маскирование номеров карт и счетов.

Тестирование:
- Модуль "tests/test_readers.py" — тесты для CSV/Excel.
- Модуль "tests/test_utils.py" — тесты для JSON и вспомогательных функций.
- Покрытие: 100% для новой функциональности, все тесты проходят.

### Поиск по описанию
Функция "process_bank_search(transactions, search_word)" ищет транзакции по подстроке
в поле "description" с использованием регулярных выражений (библиотека "re").

### Подсчёт категорий
Функция "count_operations_by_category(transactions, categories)" подсчитывает количество
операций по заданным категориям на основе поля "description" с использованием "Counter" из библиотеки "collections".

## Функционал проекта

- Чтение транзакций из JSON, CSV, XLSX.
- Фильтрация по статусу операции.
- **Поиск по описанию с использованием регулярных выражений (regex).**
- Подсчёт операций по категориям (Counter).
- Сортировка по дате.
- Маскирование номеров карт и счетов.
- Конвертация валют.
